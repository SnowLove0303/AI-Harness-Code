# Proposal: Lead Agent Orchestration & Swarm Subagent Execution Physical Decoupling

## Why
With Antigravity's release of the native Swarm feature, a fundamental architectural bottleneck must be resolved: when a single Lead Agent attempts to perform both high-level task governance (Step 0 intent ingestion, Gate 1 dossiers, OpenSpec legislation, and Gate 2 plans) and low-level code implementation (writing code, heavy local debugging, and repetitive test loops), the Lead Agent's context window rapidly clutters and exhausts token budget. This prevents the Lead Agent from staying responsive, handling concurrent tasks, or maintaining an objective macro-architectural view.

To achieve maximum throughput and industrial-grade quality, the Lead Agent must physically decouple from implementation work. The Lead Agent acts strictly as the **Coordinator / Chief Architect**: ingesting requests, legislating specifications, dispatching tasks to Swarm Subagents, and conducting final bidirectional verification. All physical implementation (coding, debugging, test suite execution) is mandatory-delegated to Swarm Subagent Workers collaborating via the shared message board.

## What Changes
1. Codify **Axiom 56: Lead Agent Orchestration & Swarm Execution Decoupling Axiom (`LEAD_AGENT_ORCHESTRATION_&_SWARM_EXECUTION_DECOUPLING_AXIOM`)** across system constitutions (`GEMINI.md`, `skills/pstack-openspec/SKILL.md`, `skills/ai-harness-openspec/SKILL.md`).
2. Codify explicit RFC 2119 requirements in `openspec/specs/orbitstack-pstack-routing/spec.md`:
   - Lead Agent exclusive orchestration role;
   - Mandatory delegation of Step 3 execution to Swarm Workers;
   - Double context shield and maximum Lead Agent availability for concurrent workflows;
   - Bidirectional binding between OpenSpec `tasks.md` and Swarm briefs;
   - Constitutional legislation and universal domain neutrality.
3. Establish Layer 2 automated verification suite (`tests/lead-agent-swarm-decoupling.test.mjs`) to mechanically enforce role boundaries and prevent Lead Agent drift.
